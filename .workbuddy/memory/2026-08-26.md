  **修复方案（待用户确认）**：① `_refreshMediaInfo` 读 `info.printerAlignment` 存 `this.printerAlignment`（默认 2=CENTER 兼容旧机）；② `computeOffsetX` 增 alignment 分支：RIGHT(0)=printableMm-labelW、CENTER(2)=(printableMm-labelW)/2、LEFT(4)=0；delta 微调照旧叠加；③ 调用点(printTemplate:438 / printTestLpapi:326 / 校准尺)传入 this.printerAlignment；④ 连接日志打印 printerAlignment 便于现场核对。
  对这台机正确 offset=48.8-20=28.8mm（比当前多右移 14.4mm）。jobW=printableMm 不变（canvas 铺满打印头、内容右移即可）。

- **PTM230X 右对齐修复调试（关键坑）**：第一版 `computeOffsetX` 已支持 alignment 分支，但 `_refreshMediaInfo` 误读 `info.printerAlignment`，
  而 `getPrinterInfo()` 返回对象【没有 printerAlignment 字段】，对齐藏在硬件 `softwareFlags` 寄存器里（SDK 内部 `(softwareFlags & 0x600)>>8`）。
  故 `info.printerAlignment` 永远 undefined，分支不触发，offset 一直走默认居中(14.38mm)。修正：改读 `info.softwareFlags`，
  `this.printerAlignment = (Number(info.softwareFlags) & 1536) >> 8`（1536=0x600=PRTA掩码），值与 SDK 日志 `printerAlignment[0/2/4]:0` 一致。
  本机 alignment=0(R0右对齐) → offset=28.77mm（内容贴最右标签[28.8,48.8]）；旧机 alignment=2 走原居中公式不变。node --check 通过。
  验证：控制台应出现 `打印机对齐方式(printerAlignment): 0 (R0 右对齐) [softwareFlags=0x...]`；打印测试页内容应在标签右端。
