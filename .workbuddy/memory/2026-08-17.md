## 回归修复：LPAPI 偏移暴涨到 36.83mm → 严重偏右（paperWidth 单位 bug）
- 用户反馈：改完 paperWidth 后打印从"偏左"变成"严重偏右"。日志确认 `printTemplate offsetX(mm): 36.83`、`drawText x:37.83`（文本跑到 50mm 标签外）。
- **根因**：`getPrinterInfo().paperWidth` 的单位是 **mm**（实测 90 = 90mm 物理底纸宽），不是"点"。上一轮误把 90 当点再 `/dpi*25.4` → 得到 7.62mm 的假"标签宽"，offset = (81.3-7.62)/2 = 36.83mm。
- **修复**：`computeOffsetX` 改正确公式 `(paperWidth_mm - 标签宽_mm)/2` = (90-50)/2 = **20mm**；paperWidth 未知时退回 `(printableMm - 标签宽)/2`=15.65mm。connect 日志改为「打印机物理介质宽(mm)」。桩测试验证 20mm / 手动 15.3 均正确。
- **教训**：SDK 字段单位要逐个核对——`printerWidth` 是点、`paperWidth` 是 mm，混用会放大/缩小偏移。

## LPAPI 换纸自适应：提取 _refreshMediaInfo
- 用户问「换模板换不同尺寸标签纸能自动适应吗」。梳理后：①换模板(改设计尺寸)两条路径都自动适应(^PW/^LL 或 startJob 尺寸随模板)；②换不同长度物理纸，间隙/黑标纸走纸长度靠传感器、必须点「写入打印机并校准」重测；③换不同宽度物理纸，水平偏移 offset=(介质宽-标签宽)/2 里的介质宽 paperWidth 原本只在 connect 读一次，换宽纸后会过期。
- 改进：把 connect 里读 getPrinterInfo 的逻辑提取成 `_refreshMediaInfo()`；`_printCalibrationLabel`（「写入打印机并校准」入口）开头先调它重读 dpi/printerWidth/paperWidth。这样换纸后点一次校准就自动更新介质宽与水平偏移，不用重连。

## LPAPI 水平偏移改为 delta 微调语义（用户：还一点点偏右 + 换尺寸能自动适应吗）
- 之前 `page.offsetXMm` 是「绝对覆盖」——填了值就固定用该值，换不同尺寸标签纸后不会自动适应。且「一点点偏右」的固定机械偏差无法与"自动居中"叠加。
- 改为 **delta 微调**：`offsetX = (paperWidth_mm - 标签宽)/2 + offsetXMm`。留空=0（纯自动居中）；填 -1.5 表示居中后再左移 1.5mm 纠正"整体偏右"。换尺寸时自动居中部分随 widthMm 重算、delta 固定 → 一次微调、永久适用。
- 设计页「水平偏移微调 (mm)」改为仅 LPAPI 显示，placeholder「0=自动居中」，并加 hint 说明正负方向。
- 桩测试：50mm 留空→20、50mm -1.5→18.5、60mm -1.5→13.5、40mm 留空→25，全部正确。

## LPAPI 偏移微调提升为全局设置（用户：模板填 -1.5 正常但测试页偏右，不想每模板都调）
- 根因：测试页 `printTestLpapi` 调 `computeOffsetX(..., null, ...)` 传 tpl=null，读不到模板 `page.offsetXMm`，所以测试页用纯自动居中 20mm、缺 -1.5 微调 → 偏右。
- 改为**全局偏移微调**：`computeOffsetX` 微调量优先级 = 模板 `page.offsetXMm`（有值向后兼容特调）> 全局 `lpapi_offset_delta`（storage，`loadOffsetDelta/saveOffsetDelta`）。模板打印/测试页/printText/校准全部吃到同一微调值，换模板换纸不用重填。
- `printerManager` 加 `getOffsetDelta()/setOffsetDelta()`；`printSetting.vue` LPAPI 区新增「水平偏移微调 (mm)」输入框（绑定 offsetDelta、@blur 保存）+ 说明 + `.ipt` 样式。
- 桩测试：全局 -1.5 → 模板(空)18.5、printTestLpapi 18.5、模板(-2 优先)18、printText 不崩，全部正确。
- 用法：在「蓝牙打印」页 LPAPI 区填一次 -1.5 保存即全局生效；模板页 offsetXMm 留空即可。

## 回归修复：偏移基准改回打印头宽（用户：测试页调到 -4.5 才对）
