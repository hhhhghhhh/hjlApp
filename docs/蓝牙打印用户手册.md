# hjlApp 蓝牙打印 · 用户手册

> 对象：仓库/车间现场使用 PDA 打印标签的人员、新接手维护的同事
> 范围：连接打印机、导入模板、编辑模板、校准、测试、业务打印、常见故障处理
> 适用机型：Zebra 系列（ZPL 指令集，SPP 蓝牙）、道臻/德佟/IB-PTM 系列（LPAPI 指令集，如 PTM230X）

---

## 1. 使用前准备

1. **手机/ PDA 蓝牙已开启**，并授予 App「蓝牙 / 附近的设备」权限（Android 12+ 必须）。
2. **打印机先配对**：在系统「蓝牙设置」里搜索并配对打印机（长按打印机蓝牙键/走纸键到指示灯闪烁即可进入可连接/配对模式）。
3. 进入 App → **蓝牙打印（设置）** 页面。

> ⚠️ 打印机必须开机、电量充足、处于可连接模式（指示灯闪烁），否则会连接失败，或连上了却对指令没反应（出纸空白）。

---

## 2. 连接打印机（设置页）

1. 打开「蓝牙打印」页：
   - 顶部显示「蓝牙状态」「当前打印机」。
   - 若蓝牙未开，点「开启蓝牙」；点「系统蓝牙设置」可跳去系统配对。
2. **选择指令集（关键）**：
   - 本机显示两个选项：**LPAPI 指令集**、**ZPL 指令集**。
   - **道臻/德佟/IB-PTM/PTM230X 等选「LPAPI 指令集」**；**Zebra（ZR/ZD/ZT/ZQ 等）选「ZPL 指令集」**。
   - 选定后 App 会**按这台打印机的蓝牙地址记住**，下次点它就自动套用，无需重选。
   - 不确定时，点设备列表里该机会按机型自动判断（IB-PTM→LPAPI，Zebra→ZPL）。
3. **连接**：
   - 在「已配对设备」里点击对应打印机 → 自动用记住的指令集连接。
   - 没出现在列表？用「按地址连接」：输入 12 位十六进制地址（如 `AABBCCDDEEFF`，机身/电池仓条码就是），或点「扫码」扫机身条码。
   - 连接成功提示「打印机已响应」；若提示「连接未确认」，说明蓝牙通了但打印机没回应状态查询——重新进可连接模式再连。
4. **设为默认**：连上后点「设为默认打印机」，以后业务页打印会自动回连这台。

## 3. 模板：从哪里来

模板有两种来源，二选一：

- **内置默认模板（三张）**：默认批次号模板、默认关键件模板、默认产品模板。首次打开自动生成。
- **从 CodeSoft 导入**（推荐，所见即所得）：
  1. 电脑上用 CodeSoft 画好 `.Lab` 标签 → 在 **CSPrintService** 里解析成二维码。
  2. 两种码：
     - **离线码**（gzip+base64，很密）：用 PDA **侧边实体扫码头**扫（摄像头读不动）。元素太多装不下时改用回连码。
     - **回连码**（稀疏 JSON，摄像头可扫）：PDA 与跑 CodeSoft 的电脑同网段、CSPrintService 在运行时，扫码后点「连接并取最新解析结果」。
  3. 进入 App → 蓝牙打印 → **从 CodeSoft 导入** → 聚焦输入框按实体扫码键（或粘贴）→ 自动解析。
  4. 解析后检查：模板名称、尺寸、纸张类型、需要的变量、转换提示。变量名要和 MES 记录里的字段名一致，否则会印成空白。
  5. 点「保存为模板」（同名会问覆盖还是另存）。

> 离线码输入框**不要写 maxlength**，否则长码会被截断在第 140 字（扫码头按键模式常踩）。

## 4. 编辑模板（标签模板页）

进入「蓝牙打印 → 编辑标签模板」：

- **标签尺寸 / 纸张类型**：
  - 尺寸：宽 × 高（mm）。
  - 纸张类型决定走纸方式：**间隙纸**（标签间有缝隙）/ **黑标纸**（背面黑条）/ **连续纸**（无间隙，按定长走纸）。**选错会导致走纸过长或跨张**，务必与实际耗材一致。
- **元素**（文本 / 二维码 / 一维条码 / 横线 / 矩形框）：
  - **文本**：
    - 「**框高/字号(mm)**」——**框高就是字号**，只填这一个高度即可；字宽=框宽，文本会按「框宽」自动换行。
    - 想只改一个高度就让字体和换行自适应：把框高填成你想要的字号，框宽填成允许换行的宽度。
    - 注意：**调小字号也可能不变小**的情况已修复；若仍不变，大多是框高字段没生效，找开发核查转换（见代码报告 3.8 节 `normalizeDetailObject`）。
  - **二维码**：
    - 短内容用模板框大小；**内容很长时 App 会自动放大到"能稳扫的最小尺寸"**（见第 6 节说明），不需手动放大。
  - 横线：宽>0 高=0；矩形：宽高都>0。
- **覆盖默认模板按钮**：把系统三张默认模板重置成 App 自带的最新版（**只覆盖这三张，你自建的模板不丢**）。日常手动保存的模板不会被自动覆盖。

---

## 5. 写入打印机并校准（重要！）

改了模板尺寸/换纸后，**必须做这一步**，否则打印错位或走纸异常：

- **ZPL（Zebra）**：
  - 连续纸：写入定长，立即生效。
  - 间隙/黑标纸：发校准让打印机传感器重新测量标签长度（会走 2~3 张）。**不校准就按旧长度走纸，标签印得偏长或跨张**。
- **LPAPI（PTM230X 等）**：
  - LPAPI **没有持久化校准指令**，尺寸每次打印随任务下发。点「写入打印机并校准」会打印一张当前尺寸的校准标签，让打印机走纸并测量间隙、确认尺寸/对齐。换纸后建议连点两三次让传感器重新学习。
- 入口：导入页保存后点「写入打印机并校准」；或模板页/设置页的「介质校准」。

## 6. 关于二维码"自动放大"（用户须知）

App 做了**二维码自适应**：内容短时用模板框；内容长（字节多）时自动放大到"按经验密度仍能扫出"的最小尺寸（约 2.15 点/模块），避免被压太密扫不出。

- **它会尽力保证可扫，但不是 100% 物理保证**：
  - 这个密度是实测经验值（批次号实测可扫密度附近留裕度），前提是打印对比度正常。
  - 若标签比放大后的二维码还小，二维码会被裁掉而扫不出——这种情况下需要换更大的标签或缩短内容。
- 早期"长短 SN 打印一个大小"的问题，在换上正确内置模板 + 点「覆盖默认模板」重生成后已解决：长 SN 会明显比框大。

## 7. 打印测试

设置页「打印测试」区：

- **LPAPI**：
  - 填「测试标签宽/高(mm)」→ 点「LPAPI 综合测试」：打一张含外框、二维码、中文、条码的标签，用于核对落点是否贴边、文字是否清晰。
  - 「LPAPI 中文文本」：快速验证中文。
- **ZPL**：「ZPL 测试」「查询状态」「查询语言」等。
- **维护**：「清除打印缓存」（卡纸/误发大批量时用）、「介质校准」、「检测中文字体」「查询 FNT/TTF 字体」。

## 8. 偏移微调（LPAPI 专属）

若打印整体偏左/偏右/偏上/偏下：

- **水平偏移微调 (mm)**：一次设置，**对所有 LPAPI 打印（测试页、模板打印、文本、校准）生效**，换模板/换纸不用重调。
  - 实测整体偏右 → 填**负值**（如 -1.5）；偏左 → 填**正值**。
  - 提示基线随打印机对齐方式自适应显示（右对齐→"0=贴右"、居中→"0=居中"、左对齐→"0=贴左"）。
- **垂直偏移微调 (mm)**：偏下填负值（内容上移）、偏上填正值（下移）。同样全局生效。
- 模板内也可单独设 `offsetXMm/offsetYMm` 做个别特调（优先级高于全局）。

## 9. 业务打印（SN / 关键件 / 批次 / 产品）

- 在对应业务页（如「关键件 SN 打印」「批次 SN 打印」「产品 SN 打印」），列表选择要打印的记录 → 点击打印。
- 打印逻辑：按该页配置的 SN 字段（如 `keySn`/`itemLotSn`/`productSn`）取值 → 填入对应模板的同名变量 → 调用 `printerManager.printTemplate`。
- **DJ 码模式**（条码扫描交互）：部分 DJ 业务码决定输入方式——
  - `DJ02 / DJ03 / DJ05 / DJ11` → **选择分录**（从列表选）；
  - `DJ12 / DJ14` → **扫码输入**（直接扫）。
  - 具体映射随业务页 `config` 配置，遇到新模式找开发在 `snPrintList` 配置里加。
- 未连接默认机会自动回连；仍未连上会明确报错，不会"以为打了其实没打"。

## 10. 常见故障排查

| 现象 | 先检查 / 处理 |
|---|---|
| **连不上打印机** | ① 打印机开机、进可连接模式（灯闪）；② 系统蓝牙已配对；③ App 蓝牙权限已授；④ 指令集选对（LPAPI vs ZPL）；⑤ 不在范围就靠近。 |
| **出纸空白** | LPAPI：多为隐藏 canvas 未就绪或尺寸未同步（开发侧）；ZPL：中文走了位图但字体/编码问题。先点「LPAPI 综合测试」验证通道。 |
| **打印偏左/印到标签外** | 设置页调「水平偏移微调」（偏右填负、偏左填正）。PTM230X 实测靠右对齐属正常，调 delta 即可。 |
| **走纸过长 / 跨张** | 换了纸/尺寸必须点「写入打印机并校准」。间隙/黑标纸靠传感器量长度；连续纸按定长。检查纸张类型选对。 |
| **中文糊 / 灰蒙蒙** | LPAPI：这是没开二值化导致——正常应已默认开启；若仍糊，报告开发。ZPL：在设置页看是否检测到 TTF 字体，或开「强制 TTF 字体」。 |
| **二维码扫不出** | 内容太长被压密 → 已自动放大；若仍扫不出，标签可能太小裁切了，换大标签或缩短内容。对比度差也可能。 |
| **模板导入提示"变量会印成空白"** | 这些是 CodeSoft 自己算的变量（计数器/公式/数据库等），PDA 取不到值，需要做成"用户输入"类型或改名匹配。 |
| **离线码扫不进** | 用 PDA 实体扫码头（不是摄像头）；或改用回连码（稀疏、摄像头可扫）。 |
| **改了模板不生效** | 手动保存的模板不会被启动覆盖；要重置三张默认请点「覆盖默认模板」。确认打印时选的是你保存的那张模板。 |

## 11. 给维护同事的快速入口

- 想看代码级定位、坑点、行号 → 读同目录 **《蓝牙打印代码分析报告.md》**。
- 改打印逻辑：适配器 `utils/adapters/*` + 渲染器 `utils/zplTemplate.js` / `utils/lpapiTemplate.js`。
- 改模板数据契约：`utils/labTemplate.js`。
- 改连接（SPP/BLE 收发）：`utils/printerConnection.js`（注意 LPAPI 自管 BLE，不经此层）。
- 隐藏 canvas / 尺寸同步：`utils/lpapi-uniplugin.js` + 各打印页的 `onLoad/onShow`。
